창고지기(소코반) 규칙 & 조작법

게임 목표

창고 관리인을 움직여 모든 나무 상자를 초록색 목표 지점 위로 밀어 넣으면 클리어됩니다.

  • 상자는 밀기만 가능하며 당길 수 없습니다.
  • 한 번에 하나의 상자만 밀 수 있습니다 (두 개 연속 불가).
  • 구석에 상자가 끼었을 때는 실행 취소(Z)나 초기화(R)를 활용하세요.

조작 안내

• 키보드: 방향키 또는 W, A, S, D / 실행 취소: Z (Ctrl+Z) / 초기화: R

• 모바일 & 마우스: 게임 보드 위에서 상하좌우 스와이프 또는 우측 하단 방향 버튼 터치
